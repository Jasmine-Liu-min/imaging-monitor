# Imaging Monitor 演示脚本（3–5 分钟）

> 一份脚本通吃三种场合：**团队群推广 / 答辩汇报 / 面试作品**。
> 按「痛点 → 现场演示 → 技术亮点 → 价值」讲，落点始终是"你只需看群消息"。

---

## 0. 演示前准备（30 秒，提前做好）

```bash
cd imaging-monitor
# 方式一：一键（自动测试 + 生成数据 + 起看板 + 开浏览器）
./start.command
# 方式二：若要展示真实 AI 数据，先联网跑一次（sonnet 更快更稳）
ANTHROPIC_MODEL=claude-sonnet-4-5 python3 -m imaging_monitor.cli run --dry-run --skip-push
python3 -m http.server 8000   # 看板 http://localhost:8000/web/
```

> 确认看板能打开、「重点动态」「竞品战卡」有内容、飞书卡片样例（`docs/飞书卡片样例.md`）已就绪。

---

## 1. 开场一句话（15 秒）

> "这是一套**竞品&市场信息 AI 自动化监控系统**——定时全网扫影像行业信源，AI 筛选验证后，每天把'行业发生了什么、对我们意味着什么'直接推到飞书群。你只需要每天花 3 分钟看群消息。"

## 2. 痛点（30 秒）

> "我们获取竞品信息的速度，常常跟不上行业变化：竞品发了新品隔几天才看到，一手爆料根本没进视野，等传到决策桌上窗口期已经过了。靠人力盯盘，**覆盖面和时效性天然有上限**，还要在一堆大模型、汽车、游戏新闻里手动扒影像相关的。"

落点：**更快感知、更全覆盖、自动降噪、不重复刷屏**。

## 3. 现场演示（2–3 分钟，主菜）

打开看板 `http://localhost:8000/web/`，按 tab 顺序讲：

| 步骤 | 点哪 | 说什么 |
|---|---|---|
| ① 总览 | 顶部趋势图 + TOP5 | "每天监控量、新增量一目了然；TOP5 是当日最该看的。" |
| ② **重点动态** | 重点动态 tab | "系统判定的高价值动态——**只留高/中威胁或建议推送的**，低价值噪音不进这里。" |
| ③ **竞品战卡** | 竞品战卡 tab | "对标 Klue 的 battlecard：按品牌聚合，每张卡有**今日新增、威胁等级、一句战略含义**。比如大疆这张：618 战报反映其市场份额与品类竞争力。" |
| ④ 今日新增 | 勾"仅看今日新增" | "跨运行去重——同一条新闻只在首次出现时推送，**不重复刷屏**。" |
| ⑤ 证据链 | 任一卡片"来源"链接 | "每条结论都能**点回原始链接**，过滤水文和臆测。" |

然后打开 **`docs/飞书卡片样例.md`**：

> "这是每天真实推到群里的卡片——顶部'今日新增 N 条'，'重点竞品 battlecard'摘要，再到分栏明细。**同事不用打开任何工具，群里扫一眼就够了。**"

## 4. 技术亮点（30 秒，面试/技术评审向）

> "几个关键设计：
> - **只保留影像**：送 AI 前用品牌词 + 影像锚点词严格降噪，把 200+ 候选压到 30 条影像相关，省 token 也更准；
> - **跨运行去重**：稳定 id 记忆历史，只报'变化'；
> - **AI 永远可降级**：无 key→规则、报错→兜底、坏 JSON→重试、分析阶段失败→保留抽取结果，流水线永不崩；
> - **证据优先**：无可回溯链接不推送；
> - **零第三方依赖**：纯标准库，跑在 GitHub Actions 上，几乎零成本。"

## 5. 价值收尾（20 秒）

> "今天真实跑出来的就有：大疆 Pocket 4P 口袋电影机发布、Osmo 618 全品类登顶、影石将推 AI 全景剪辑——**都是一手竞品动态**。
> - 产品同学：第一时间掌握竞品，辅助规划与差异化；
> - 市场/运营：快速抓行业热点和竞品营销动作；
> - 所有人：每天 3 分钟，保持对行业的敏锐度。"

## 6. 预期问答（详见 [README 面试 Q&A](../README.md#-面试可能会问qa)）

- **为什么不全量丢给 AI？** 成本/噪音/token → 规则先降噪到 30 条再交 AI。
- **怎么不重复推送？** 稳定 id 跨运行去重，只报新增/变化。
- **AI 挂了怎么办？** 三层降级，流水线永不空跑。
- **怎么保证不是水文？** 证据链 + 来源分级 + 无证据不推。
- **怎么对标 Crayon/Klue？** 影像垂直 + 零依赖 + 自托管 + 近零成本。

## 7. 演示注意 / 已知可优化点（坦诚应对追问）

- **残余噪音**：`无人机` 锚点会带进军事/农业/航拍打卡类新闻（如"无人机狂轰俄本土"）。这类已被判 `dashboard_only` 不推送，但仍会出现在看板。**可优化**：给军事/农业等加排除词，或要求"无人机"需与影像品牌共现。
- **重要性区分度**：当前部分条目重要性偏高（★★★★★ 偏多），分析阶段未充分拉开差距。**可优化**：在分析师 prompt 里强制重要性分布。
- **AI provider 选择**：项目 provider 无关，默认用便宜稳定的 **DeepSeek**（OpenAI 兼容、长 JSON 不截断）；候选**分片+并发**送入 AI，单片失败只降级该片。要更强语义可切 OpenAI / Claude。

> 这些都是"已知且有解"的点，主动讲出来比被问到更显专业。
